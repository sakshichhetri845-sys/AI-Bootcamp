# AI-Bootcamp
Basic python Programs and Machine Learning Assignments

## Overview
- **Assignment1**: Basic Python programs (odd/even, palindrome, prime check, reverse, product).
- **Assignment2**: Object-oriented programming (Library management system).
- **Assignment3**: Data science basics with NumPy, Pandas, Matplotlib, and exploratory data analysis.
- **Assignment4**: Stroke Prediction Machine Learning project (`stroke_prediction.ipynb`) featuring data preprocessing, exploratory data analysis, class imbalance handling, and model evaluation (Logistic Regression, KNN, Decision Tree, Random Forest).
